# PENGUJIAN PROGRAM ANALISIS NILAI MATEMATIKA

## Tujuan Pengujian

Pengujian dilakukan untuk memastikan program dapat membaca,
memvalidasi, menghitung, dan menyimpan hasil analisis nilai
siswa dengan benar.

## Daftar Pengujian

| No. | Kasus Pengujian | Input | Hasil yang Diharapkan |
|---|---|---|---|
| 1 | Data normal | 8 data siswa | Rata-rata 76.25 |
| 2 | Nilai batas bawah | 0 | Nilai diterima |
| 3 | Nilai batas atas | 100 | Nilai diterima |
| 4 | Nilai melebihi batas | 101 | Nilai ditolak |
| 5 | Nilai negatif | -5 | Nilai ditolak |
| 6 | Input bukan angka | abc | Nilai ditolak |
| 7 | Data kosong | File kosong | Statistik tidak dihasilkan |
